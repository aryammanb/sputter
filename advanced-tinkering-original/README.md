# Magnetron reconstruction and development sources

This historical directory name includes the original reconstruction and later gun/magnetic studies. Start with the [current selection](../design/current.json), which points to the R06 gun under `chamber-design`.

The twelve-stack study and its nonlinear FEM data are retained here as engineering evidence. Original magnetic results used a 2 mm target. The current 3.175 mm target-plane assessment is [documented separately](../simulations/current-target-r06/README.md).

Older mechanical notes and component names can contain superseded sizes/material labels. Current geometry and selection records take precedence. Original source video, download-tool dependencies and browser profiles are excluded from the repository. CAD, engineering scripts and meaningful simulation records are preserved.
