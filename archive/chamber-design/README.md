# Earlier chamber and system iterations

These are preserved design stages, not the current manufacturing or procurement selection. Start with [System architecture and CAD](../../docs/design.md) or the [active source directory](../../chamber-design/README.md).

| Folder or record | Historical scope |
|---|---|
| [top-plate-r01](top-plate-r01/) | Preliminary chamber-roof and gun-port layout |
| [complete-chamber-r01](complete-chamber-r01/) | First complete chamber, stage/shutter parts and loading states |
| [compression-fitting-r02](compression-fitting-r02/) | Earlier detailed mounting gland and its assembly demonstration |
| [full-system-r03](full-system-r03/) | First integrated pumping/gas system and supplier reference geometry |
| MFC R01–R03 notes | Earlier flow-range calculations and 200 sccm selection, superseded by the 500 sccm R04 note |
| update_mfc_r03_links.py | Historical R03 documentation-update script; not a current selection updater |

Some later authoring scripts still read these source models. The folders retain their internal geometry, part files and evidence; archived STEP/native CAD bytes are unchanged. The active R04/R05 source revisions remain under `chamber-design/` because they directly support the current R06 assembly.

Old filenames containing “Current” refer to their own revision. Old walkthroughs and operating assumptions are historical. Folder moves are recorded in [the layout map](../../chamber-design/layout.json).
