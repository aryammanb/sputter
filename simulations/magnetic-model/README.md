# Magnetic-model evidence

This is the numerical magnetic study used by the current R06 target-plane assessment. It is retained independently of the removed original CAD reconstruction.

The saved refined field, meshes, solver/analysis code, B-H assumptions, baseline metrics and numerical checks support [the current target-plane calculation](../current-target-r06/README.md). `yoke.step` is the magnetic study's yoke input. No new solve or geometry change was made during this cleanup.

The baseline uses a 2 mm nonmagnetic target; the current assessment resamples the field for the 3.175 mm target. Baseline field plots are calculation evidence, not current-system photos or an operating demonstration. See [simulation scope and limits](../../docs/simulations.md).
